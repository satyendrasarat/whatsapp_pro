2. COMPLETE FEATURE MATRIX TO HIGHLIGHT IN VIDEO ASSETS
================================================================================

1. CORE ARCHITECTURE & PRIVACY:
   • Built on embedded SQLite with node:sqlite WAL mode (ultra-fast, zero SQL server required).
   • Direct multi-device TLS communication via @whiskeysockets/baileys.
   • Local desktop operation with zero per-message server fees or cloud lock-in.

2. MULTILINGUAL AI & VOICE TRANSCRIPTION:
   • Native Voice-In -> Text-Out engine using Gemini 3.5 Flash-Lite multimodal STT.
   • Supports Hindi, Hinglish, English, and regional dialect voice notes.
   • In-memory pure JS 16kHz WAV converter with waveform duration parsing.

3. VISUAL AUTOMATION FLOWS:
   • Drag-and-drop React Flow canvas with custom nodes.
   • Keyword Triggers (supports comma-separated triggers & '*' catch-alls).
   • Interactive Menu Nodes with custom options and branching handles.
   • Dynamic AI Handover & Live Human Support Escalation nodes.

4. 2-WAY LIVE CHAT INBOX & ESCALATION:
   • Real-time operator inbox with WebSocket bidirectional sync.
   • One-click bot pause toggle for instant human takeover.
   • Custom conversation labels (VIP, Lead, Urgent, Follow-up).
   • WhatsApp Handover Alerts dispatched directly to owner's self chat or custom alert phone.

5. BULK CAMPAIGNS & ANTI-BAN SUITE:
   • Campaign dispatcher with audience list segmentation.
   • Anti-Ban human typing simulation (emulates WhatsApp presence typing).
   • Randomized jitter delay (8–20s) between messages.
   • Batch pause cooldown (e.g. 15 messages sent -> 40s resting period).

6. GROUP GRABBER & LID RESOLUTION:
   • Scrapes all group members and participants from joined WhatsApp groups.
   • Automatic LID (Linked Identity) to phone number resolver and caching engine.
   • One-click export to targeted audience lists.

7. MONITORING & MAINTENANCE:
   • Live Engine Activity & Error Analysis terminal with Refresh and Copy.
   • Auto-rotating disk logging (crm_activity.log with 10MB limit).
   • Danger Zone Factory Reset with double-confirmation ('RESET') safety guard.
